# Application Scorecard Model

## Project Overview

This project demonstrates the development of an **Application Credit Scorecard** using the `credit_default` dataset from the Kaggle.

The objective is to develop a scorecard that ranks applicants according to their estimated credit risk using credit risk modelling techniques.

## Methodology

The project follows an end-to-end scorecard development process:

* Data cleaning and exploratory analysis
* Missing value and invalid value treatment
* Initial variable binning
* Weight of Evidence (WOE) transformation
* Information Value (IV) calculation
* Variable selection and correlation analysis
* Bin merging and risk pattern assessment
* Logistic Regression modelling
* Model validation and performance assessment
* Score scaling and development of the final scorecard


## Files

* **Jupyter Notebook** — Complete implementation of the application scorecard model.
* **Word Document** — Detailed explanation of the scorecard methodology and mathematical concepts.
